18. GROQ AI
============================================================

Groq is used as the reasoning/explanation layer.

Do NOT use Groq for every game event.

Bad:

player moves
→ Groq

player moves
→ Groq

kill
→ Groq

weapon switch
→ Groq

This will waste free limits.

Correct:

RAW EVENTS
↓
LOCAL STATE ENGINE
↓
EVENT AGGREGATION
↓
TACTICAL ENGINE
↓
GROQ WHEN DECISION IS REQUIRED

Possible Groq triggers:

- pre-match
- map selected
- round ended
- economy change
- major opponent pattern
- side switch
- clutch
- timeout
- match finished

Use cooldowns.

Cache context.

Use compact JSON.

Handle 429.

Read rate-limit headers when available.

Never crash because Groq is unavailable.
